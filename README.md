# Hi, I'm Raazi

I'm building software focused on turning operational data into clear, actionable workflows.

## Currently Building

### FollowUpOS

**Revenue Action OS**

FollowUpOS is a revenue operations platform designed to answer one question:

> What needs action now?

It transforms customer activity, opportunities, quotations, invoices, payment commitments, and follow-ups into prioritized commercial actions.

### Current capabilities

- Revenue Command Center
- Prioritized action intelligence
- Customer account intelligence
- Opportunity and pipeline tracking
- Quotation management
- Invoice and cash-exposure monitoring
- Payment commitment tracking
- Follow-up management
- Team workspaces and role-based access

## Tech Stack

- Next.js
- TypeScript
- React
- Supabase
- PostgreSQL
- Tailwind CSS
- Git & GitHub

## Current Focus

I'm currently developing the full revenue action loop:

**Detect ? Prioritize ? Act ? Resolve ? Clear**

Future work includes data migration and integrations for businesses already using systems such as Tally, Zoho, and SAP.
